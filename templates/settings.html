Google Gemini AI Configuration

The application connects to the official google-genai SDK to provide conversational insights, savings strategies, and budget advice.

To connect a live Google Gemini API Key:
  1. Get a free Gemini API key from Google AI Studio.
  2. Open the .env file in the project root directory.
  3. Set GEMINI_API_KEY=your_actual_api_key_here.
  4. Restart the Flask server.
Zero-Setup Guarantee: If no API key is provided, the application engages its built-in rule-based financial advisory engine with 100% functionality!
